## Wayback link harvest

Run `python3 scripts/harvest_wayback.py /tmp/wayback-harvest.csv` from the repository root. The script uses the Python standard library and queries the Internet Archive. It reports original URLs, candidate playback URLs, capture timestamps, and Markdown references.

Review the playback and cited content before adding a candidate to the bibliography. The accompanying harvest includes a manually reviewed capture for the IFLA *Final Report on Aggregates*. A fresh run reflects the Archive's current results.
