title: Titling of Item Digital Filenames
---
<a id="sec-title_titling_of_item_digital-filenames"></a>
<!-- ### Titling of Item Digital Filenames -->

There is no one standard for naming digital files as the nature of materials and collections in different institutions and organisations are very different - as are their systems.

It is preferable to utilise the unique identification number of the actual Item record within the filename if possible, as this is less likely to change potentially, e.g. titles and other elements could change on the Item in the future, which would possibly mean having to rename the file itself as well.  Barcodes and location numbers can change over time as well so are riskier to use. 



However, if you have a system that doesn't have such a less mutable unique number, or more identifying details are needed within the filename for best access to any of your users, then the descriptive file names you have come up with are good and are following the consistently "best practice" structures that seem to be used across a wide variety of organisations and digital files (digitised images and digitised moving images).

The consistently used file naming practices fundamentally seem to be the following:

1) Omit special characters, eg. * ( [?@', + = and use only underscore _ hyphens - or . full stops.
2) Use alphabetical A-Z, or a-z [some use just lower case, others a mixture of upper and lower case - often with capitalisation of initial letter of each word]
3) Either omit spaces (also tabs, returns, etc.) altogether or replace with a hyphen.
4) Omit initial articles (e.g the, a, etc.) - with option of also omitting other articles within the film title element of the filename for further abbreviation of title, e.g. WindInWillows, rather than  WindInTheWillows. [NB. Abbreviating titles further is also fine but good to have a standardised practice, eg. word Adventure is always abrreviated to Adv (or whatever form is preferred) rather than different practices by different cataloguers, eg. Adv, Advt, Advnt. With 1 in mind also omit apostrophes or other punctuation from the title]
5) Use lead zeros with numbers, eg. 01, 03, 09, etc. 
6) Additional file naming components, such as full dates, should be separated with a hypen - instead of an underscore, eg. 1965-10-02
7) Always include the 3 character file extension identifier (preceded by a full stop) to end the filename, eg. .jpg, .mp4, .mov [NB. lower case seems to be the preferred option with these]
8) Do not use more than one full stop . in a filename and limit its use to preceding the three character file extension at the end of the filename. 

Additional suggestions:

a) Use ISO dates, so that full date if known can be included, partial dates or just year, e.g. 
                               
                                    TimeOfFury_1965-10-02.mov
                                     TimeOfFury_1965-10.mov
                                     TimeOfFury_1965.mov

      If including circa dates then put in front of the date with no space:

                                     TimeOfFury_c1965.mov
                                    
b) Indicate extent, ie. number of files that make up the moving image concerned, and ideally retain same number within the folder for the one moving image, even if it is made up of 3 digital files, e.g.

                                     F_147_1_TimeOfFury_1965_01of03.mov
                                     F_147_1_TimeOfFury_1965_02of03.mov
                                     F_147_1_TimeOfFury_1965_03of03.mov

rather than
                                     F_147_1_TimeOfFury_1965.mov
                                     F_147_2_TimeOfFury_1965.mov
                                     F_147_3_TimeOfFury_1965.mov
                                     F_147_4_Watchman_1981.mov

If there is only one file then it would simply be:

                                     F_147_1_TimeOfFury_1965_01of01.mov

This both makes it clearer that the files belong to the one entity, and also clarifies the order in which the digital files should be run/viewed. 

There is also then the option of adding other distinguishers if needed too, if there is a duplicate copy of the film but in for example HD or Dolby Stereo, etc. and you want to be able to denote which file of the film is which, e.g.

                                     F_147_2_TimeOfFury_1965_HD_01of03.mov

c) Consider other acquired moving image materials relating to the film, eg. trailers, rushes, production material etc. that might be acquired and which stylistic options would be preferred within the filename to distinguish them, e.g.

                                     F_147_1_TimeOfFuryTrailer_1965_01of01.mov
                                     F_147_1_TimeOfFury_Trailer_1965_01of01.mov
                                     F_147_1_TimeOfFury_tlr_1965_01of01.mov
                                     F_147_1_TimeOfFury-Trailer_1965_01of01.mov

d) Also inclusion of other metadata for disambiguating, eg. if you have two different films with identical titles and release years you could add director's full name or surname, i.e.

                                     F_147_23_Hamlet_1965_Smith_01of01.mp4
                                     F_147_23_Hamlet_1965_JohnSmith_01of01.mp4
                                     F_147_23_Hamlet_1965_JSmith_01of01.mp4
                                     F_147_34_Hamlet_1965_Jones_01of01.mp4
                                     F_147_34_Hamlet_1965_DavidJones_01of01.mp4

or other identifier such as production country.

b), c) and d) are all necessary to help in identification and in ensuring that each file has a unique name as you can't store 2 files with the same name as it risks one file over-writing the other.

If you should ever introduce a structure of sub-folders then use a hyphen rather than full stop to distinguish that sub folder element, e.g.

                                         F_147-1_1_TimeOfFury_1965_01of01.mov
                                         F_147-4_23_Hamlet_1965_Smith_01of01.mp4
