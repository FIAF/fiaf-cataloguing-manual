 
3.1.5.16 Codec vidéo

Il s'agit du standard de compression vidéo utilisé dans l’Item vidéo numérique, par exemple, D10,

MP4, etc.

Les fichiers vidéo et de cinéma numérique se trouvant dans des formats conteneurs comportent des
fichiers audio séparés. Par exemple, les DCP (encapsulés en MXF) sont composés d'un fichier vidéo JPEG2000
et d'un fichier audio WAV (ainsi que d'informations textuelles dans un fichier XML). Le codec audio est décrit
séparément.

La sélection doit se faire à partir d'une liste contrôlée. Une liste de propositions, ouverte et non

exhaustive, se trouve dans D.7.10 Item. Type de codec. D'autres listes existent :

Vocabulaire PBCore essenceTrackEncoding:
http://metadataregistry.org/concept/list/vocabulary_id/156.html

EBUCore Video Compression Code :
https://www.ebu.ch/metadata/cs/ebu_VideoCompressionCodeCS_p.xml.htm
