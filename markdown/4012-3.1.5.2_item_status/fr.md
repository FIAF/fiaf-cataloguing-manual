 
3.1.5.2 Statut de l’Item

Il s'agit de la description du statut de conservation ou d’accès de l’Item, p. ex. Master, copie de
visionnage, etc. Sélectionnez un terme dans une liste contrôlée. Une liste de propositions, ouverte et non
exhaustive, se trouve dans D.7.3 Item. Statut de conservation/d’accès.
