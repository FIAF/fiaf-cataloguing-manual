 
2.3.4.4 Farbeigenschaften einer Manifestation

Das Vorhandensein von Farbe(n), Tonung(en) usw. in einer Manifestation.97

Unter Farbe versteht man alle Farbeindrücke einschließlich Schwarz und Weiß, die in einer
Manifestation enthalten sind.98

Die Farbeigenschaft einer Manifestation, z.B. schwarz-weiß (getönt), Farbe, Farbe + schwarz-weiß,
usw. sollte erfasst werden. Die Auswahl sollte aus einer kontrollierten Liste von Begriffen getroffen
werden. Eine Vorschlagsliste finden Sie in D.7.11 Farbtyp (Manifestation/Exemplar).

Optional beschreiben Sie das System oder den Prozess, mit dem die Farbe auf dem Träger oder als Teil
der digitalen Kodierung fixiert wird, z.B. Pathécolor, Technicolor, RGB usw. Die Auswahl sollte aus
einer kontrollierten Liste von Begriffen getroffen werden. Eine Vorschlagsliste findet sich in D.7.12
Farbverfahren (Manifestation/Exemplar).
