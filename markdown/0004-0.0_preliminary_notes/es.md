# 0.1 Propósito, alcance y uso

# 0.1.1 Propósito

Los propósitos primarios del Manual FIAF son: sugerir recomendaciones para la descripción e identificación de imágenes en movimiento (con énfasis en imágenes en movimiento de archivos); y definir los elementos de la descripción que facilitan el intercambio de información.
