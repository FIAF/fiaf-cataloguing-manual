 
0. Notes préliminaires

0.1. Objectif, portée et utilisation

0.1.1. Objectif

Les principaux objectifs du présent manuel de la FIAF consistent à suggérer des recommandations
pour la description et l'identification des images animées (l'accent étant mis sur les images d'archives
animées) et de définir les éléments de description pour faciliter l'échange d'informations.
