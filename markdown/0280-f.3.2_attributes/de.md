 
F.3.2 Attribute

Dieses Handbuch enthält eine granulare Nomenklatur für die Beschreibung der Attribute der
Entitäten Werk, Variante, Manifestation, Exemplar. In den Leitlinien werden die Attribute für diese
Entitäten, z.B. Agenten (d.h. Personen, Familien, Körperschaften usw.), nicht spezifiziert. Für die
Erfassung der Attribute von Agenten (z.B. Vorname, Nachname, Staatsangehörigkeit usw.) wird auf
Standard verwiesen, wie z.B. Functional requirements for authority data: a conceptual model oder
Tools wie das Library of Congress Name Authority File.244
