 
F.3.2 Attributs

Le présent manuel fournit une nomenclature détaillée permettant de décrire les attributs des entités
de l'image animée, à savoir l'Œuvre, la Variante, la Manifestation et l’Item (WVMI). Les recommandations ne
précisent pas les attributs des entités liées aux entités WVMI, par exemple, les agents (c'est-à-dire les
personnes, les familles, les collectivités, etc.). Pour enregistrer les attributs des agents (par exemple le
prénom, le nom de famille, la nationalité, etc.), il convient de se référer à des sources faisant autorité, telles
que les Fonctionnalités requises des données d’autorité : un modèle conceptuel ou des outils tels que le Library
of Congress Name Authority File ou le fichier d’autorité des noms de personnes de la Bibliothèque nationale
de France.243
