 
1.3.1.1. Vrsta identifikacijske oznake

Ako sustav ustanove dopušta, kvalifikator „Vrsta“ može se upotrijebiti uz identifikacijsku oznaku

kako bi se definirao njezin izvor.

Primjeri:

Identifier type: EIDR

Identifier type: ISAN
