 
2.3.3.1 Begriffe für Sprachen

Wenn möglich, erfassen Sie die Sprache(n) mit der vollen Namensform, z.B. Französisch, Italienisch
usw., und nicht mit Abkürzungen oder Codes, indem Sie den/die geeignetsten Wert(e) aus einer
kontrollierten Liste nehmen. Dies kann eine hausinterne Liste sein, aber eine Standard-Sprachenliste
wie ISO 639 ist zu bevorzugen.

Optional können Sie den Sprachcode gemäß ISO 639 verzeichnen.

Wenn keine Sprache ermittelt werden kann, kann die Information weggelassen oder mit dem Wert
"nicht bekannt" angegeben werden.
