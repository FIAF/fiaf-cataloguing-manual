 
3.3.1 Agents

Un Agent lié à un Item est défini comme une entité impliquée dans l’acquisition, les mouvements
(pour les prêts, les analyses, le stockage, etc.) ou la conservation d’un Item. Il est considéré comme ayant
une responsabilité majeure, ou étant d'une importance majeure pour l’Item. Dans les Agents, on fait
habituellement la distinction entre les personnes physiques ou morales, les familles et les groupes de
personnes.121

Les Agents peuvent également avoir des relations avec une instance d'un Événement spécifique ou

une « autre Relation » associée à l’Item.
