# 3.1.5.19 Line standard – Video<a name="manual-3.1.5.19"/>

Describes the number of scan lines which make up the image and indicates the res- olution, for example, 405, 525, 1080. Selection should be made from a controlled list of terms. A suggested list, which is open and not exhaustive, can be found in [D.7.21 Item Line Standard – Video](#manual-D.7.21).
