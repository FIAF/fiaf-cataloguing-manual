 
1.3.5.1 Noms de langues

Enregistrez le(s) langue(s) en choisissant la valeur la plus juste dans une liste contrôlée.

Il peut s'agir d'une liste interne, mais il est préférable d'utiliser une liste de langues normalisée telle

que les codes ISO 639, y compris ISO 639-2, 639-3 et 639-5 (http://www.loc.gov/standards/iso639-
2/langhome.html).

Alternativement, vous pouvez enregistrer le code de la langue tel qu'il figure dans la norme ISO 639,

si cela est permis dans votre institution.

Si aucune langue ne peut être déterminée, l'information peut être omise ou indiquée par la valeur «

inconnue ».
