 
2.3.2.1 Type de titre

Si la Manifestation comprend plusieurs titres, tels que le titre dans une autre langue pour une
Variante doublée ou sous-titrée, vous pouvez enregistrer les différents titres et leur associer à chacun un «
type de titre » pour les différencier (voir l'annexe A, Titres et types de titre).
