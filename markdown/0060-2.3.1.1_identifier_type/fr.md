 2.3.1.1 Type d’identifiant

Si le système de l’institution le permet, comme dans le cas des identifiants d’Œuvres/Variantes, un

« type » peut être appliqué à un identifiant pour en indiquer la source.

87 Le V-ISAN représente le troisième segment du numéro ISAN, qui se compose d'un nombre 96-bits structuré comme suit: le
premier segment est la racine qui identifie l'œuvre, le deuxième est le segment épisode qui identifie la partie d'une œuvre en
plusieurs parties, le troisième est le segment version qui identifie les Variantes et les Manifestations (notamment en ce qui
concerne les changements de format et leurs «versions médias», tels que les Blu-Ray, les fichiers numériques, les cassettes, etc...) :
voir https://www.france-isan.org/images/guide-5.pdf.
88 DOI (= Digital Object Identifier): voir http://www.doi.org/.
