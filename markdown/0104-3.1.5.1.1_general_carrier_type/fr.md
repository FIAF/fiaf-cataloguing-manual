 
3.1.5.1.1 Type de support général

Il s'agit du type de support général de l’Item (p. ex., film, vidéo, audio, optique, numérique, etc.). La
saisie de ces informations de niveau général permettra une recherche ciblée sur les films, les vidéos, les
fichiers numériques, etc. plutôt que de faire une recherche sur tous les formats et supports possibles.

Enregistrez cette information seulement si elle ne se trouve pas au niveau Manifestation ou si le

système l’exige au niveau Item.

Une liste de propositions, ouverte et non exhaustive, se trouve dans D.7.1 Manifestation/Item. Type

de support général.

Pour des raisons d’intelligibilité et pour éviter la redondance, les institutions peuvent se passer
d'indiquer le type de support général puisqu’il est implicitement contenu dans le type de support spécifique.
