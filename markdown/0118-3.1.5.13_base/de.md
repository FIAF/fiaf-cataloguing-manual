 
3.1.5.13 Träger

Der Träger bezeichnet das physische Material oder Videoformat, auf dem das Exemplar aufgenommen
wurde, z.B. das flexible, transparente Material, das die Emulsion eines Exemplars oder einer
Magnetspur trägt (z.B. Azetat, Nitrat, CTA usw.). Wählen Sie aus einer kontrollierten Liste von
Begriffen. Eine Vorschlagsliste, die nicht abschließend ist, finden Sie unter D.7.7 Träger (Exemplar).
