 
3.1.5.13 Base

Le matériel physique ou le format vidéo sur lequel l’Item est fixé, décrivant par exemple le support
souple et transparent sur lequel est fixée l’émulsion d’un film ou d’une bande magnétique (p. ex. acétate,
nitrate, triacétate, etc.). La sélection doit se faire à partir d'une liste contrôlée. Une liste de propositions,
ouverte et non exhaustive, se trouve dans D.7.7 Item. Base - Film ou vidéo.
