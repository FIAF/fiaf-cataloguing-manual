# 3.1.5.13 Base {#manual-3.1.5.13}

The physical material or video format on which the Item is captured, for example, de- scribing the flexible transparent material that supports a film items’ emulsion or a magnet- ic track, (e.g., acetate, nitrate, CTA, etc.). Select from controlled list of terms. A suggested list, which is open and not exhaustive, can be found in [D.7.7 Item Base – Film or Video]().
