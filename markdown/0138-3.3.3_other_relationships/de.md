 
3.3.3 Sonstige Beziehungen

Sonstige Beziehungen markieren Beziehungen, die nicht unter die bisher genannten Beziehungen
zwischen Agent und Ereignis fallen. Dazu können Zusammenstellungen aus praktischen Gründen
gehören, d.h. wenn eine Institution Kopien von zwei oder mehr Filmen auf eine Rolle/Band/DVD usw.
zur platzsparenden Aufbewahrung übertragen hat.127
