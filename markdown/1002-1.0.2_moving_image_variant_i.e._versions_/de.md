Daher ist diese Entität optional. Wenn sie eingesetzt wird, ist jede Instanz einer Variante mit einem
Werk verbunden und kann eine “Eins-zu-viele-Beziehung” zu Instanzen einer Manifestation, einem
Ereignis, einem Agenten und sonstigen Beziehungen haben. Wenn keine Variante eines Werkes
existiert, kann diese Entität weggelassen werden, wodurch die Instanz eines Werkes mit einer oder
mehreren Instanzen der Manifestation verbunden wird.
